# Stock-Fallback-analyzer
Real Time Stock analyzer with AI Strategic suggestion built with OpenAI API.

#股票分析器 Pro - Python 桌面版

#📦 安裝步驟：
1. 安裝 Python 3.8+ (https://www.python.org/downloads/)
2. 打開命令提示符，安裝依賴：
   pip install -r requirements.txt
3. 運行程式：
   python stock_app.py

#🔨 轉成 EXE (可執行檔)：
1. 安裝 PyInstaller:
   pip install pyinstaller
2. 執行 build_exe.bat
3. dist\stock_app.exe 就是獨立執行檔

#✨ 功能：
✓ K 線圖 + 成交量
✓ 技術分析 (MA20, MA50, RSI)
✓ 基本面分析 (P/E, EPS, ROE, Debt/Equity, Profit Margin)
✓ 按鈕解讀趨勢
✓ 最新數據顯示

#📌 注意：
- 美股直接用代號 (AAPL, NVDA)
- 港股加 .HK (0700.HK, 9988.HK)
